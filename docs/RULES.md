# 量子围棋 · 规则

版本 1.0。本文档同时是游戏内「规则」页面的文字来源。

## 一、它和围棋的关系

量子围棋的吃子、气、劫、地盘都沿用围棋。区别只有一处：**落子可以同时落在两个点上**，于是棋局会分裂成两个都可能成立的世界。你要在这两个世界里同时下棋，最后按各自的可能性加权计分。

## 二、基本盘面

- 棋盘可选 5 路、9 路、13 路、19 路，交叉点落子。
- 黑先。落子在交叉点上，不能落在已有棋子的点上。
- 气、提子、禁止自杀、立即回提（劫）都按围棋规则。

## 三、常规步

点一个空交叉点，落一颗子。这一手只影响当前所在的这个宇宙。

## 四、量子步

点「量子步」，然后在同一个宇宙里点两个空交叉点 A 和 B。

这一步不会只发生一次：正在下棋的那个宇宙当场裂成两个**平级**的宇宙。

- 一个宇宙里落着 A 点上的子；
- 另一个宇宙里落着 B 点上的子；
- 两边各拿一半可能性，继续各自行棋。原来那个宇宙作废。

例如 100% 的棋盘落一次量子步，就变成两个各 50% 的宇宙；再对其中一个落一次，它裂成两个 25% 的宇宙，局面一共三个宇宙，权重分别是 50%、25%、25%。权重永远加起来等于 100%。

为了避免棋盘变成一堆没人看得懂的小数点，有两条限制：

- 一局最多同时存在 **6 个宇宙**；
- 权重低于 **8%** 的宇宙不能再分裂（再分下去就是 4%，不值得看）。

## 五、虚子

每次分裂，两颗新落下的子里有**恰好一颗是虚子**（50%），另一颗是实子——哪边是哪边，双方都看不到。这就是这个游戏的核心：你打的是不完全信息。

虚子会**沿分支继承**：

- 一个宇宙被分出去时带着虚子，它以后分裂出的两个宇宙都继续带着这颗虚子；
- 每次分裂又在一个新宇宙里加一颗虚子。

所以一个 13% 的宇宙（经历过 3 次分裂）身上可能挂着 0～3 颗虚子，看它每次分裂时落在虚的一侧还是实的一侧。

虚子在规则上和普通棋子没有区别：占点、有气、会被提。

## 六、观测与坍缩

**虚子参与提子、或者被提，就是一次观测。** 观测一旦发生，虚子的真假就定了：它是虚的，那个宇宙从来就不存在。

- 那个宇宙连同它下面所有分裂出来的宇宙一起崩解；
- 它们占据的权重全部交给同一次分裂出来的另一个宇宙——那个一直是真的兄弟。

所以虚子既是软肋也是钥匙：你知道这一手的两颗里有一颗靠不住，但不知道是哪颗。想把棋局收回一个确定的世界，就得去试探、去提。

观测之前虚子看不出来。对局结束后点「复盘」，可以逐步回看：那时的虚子会标成紫色虚线，并且和同一次分裂的**对应实子**一起标出来（哪个宇宙、哪个坐标）。

宇宙只剩一个、权重回到 100% 的时候，棋局就回到普通围棋。

## 七、轮流与封印

- **每个宇宙各自记回合。** A 宇宙轮到黑棋时，黑棋在 A 宇宙落子；白棋可以选择去 B 宇宙落子。你可以用 Tab 或点击切换当前宇宙。
- 在某个宇宙里连续两次「停一手」（黑白各一次），这个宇宙就被**封印**，不能再落子，但仍然按权重计分。
- 所有宇宙都被封印后，对局进入**结算阶段**（见下一节）。

## 八、死子与确认

进入结算阶段时，棋盘上可能还有能被提掉、但双方都不想再下的死子。这些子如果按活子算，分数就是错的。

结算阶段的规则：

- 点击任意一颗棋子，把它标记为死子（再点一次取消）。被标记的棋子会变暗并打上红叉。
- 标记对所有宇宙分别进行，双方看到的是同一套标记。
- 任何一方改动标记后，之前的确认全部作废。
- 双方都确认后，被标记的棋子从棋盘上拿走，按最终局面计算加权目数，对局结束。

单机双人模式下，一次「确认结算」同时代表双方确认。

## 九、胜负

每个存活的宇宙单独做一次数子（中国规则：活子 + 围住的空点），再乘以这个宇宙的权重：

```
黑方总分 = Σ (各宇宙黑棋数子 × 该宇宙权重)
白方总分 = Σ (各宇宙白棋数子 × 该宇宙权重)
```

总分高的一方获胜。平局按无胜负处理。

投降直接判负。

## 十、上手建议

1. 量子步不是「多下一手」，是「把棋局押成两份」。在哪个世界投入棋力，是这游戏真正的决策。
2. 虚子看不见，但两种世界都由你参与塑造：把对手的棋下在「可能是假的」那一侧，他就得为自己的判断买单。
3. 权重低的分支（12%、6%……）不值得花太多手，除非它上面的目数差异极大。
4. 想收局时，主动去提对手可能落过量子步的那一侧：提对了，那个世界就并回另一个，不确定的分变成确定的。

## 十一、术语对照

| 中文 | 英文 | 含义 |
|---|---|---|
| 宇宙 | universe | 一种可能成立的世界 |
| 权重 | weight | 该宇宙的可能性百分比 |
| 量子步 | quantum move | 一次落两个点、把宇宙裂成两个的落子 |
| 虚子 | phantom stone | 分裂时可能根本不存在的棋子：一次分裂恰好留一颗，沿分支继承 |
| 观测 / 坍缩 | observation / collapse | 虚子参与提子或被提时判空，该分支连同子树消失 |
| 封印 | sealed | 双方连续停手后该宇宙终止落子 |
| 复盘 | replay | 对局结束后逐步回看，会标出当时的虚子 |
